# 🎮 Valorant HTML

Projeto desenvolvido com o objetivo de criar um site informativo sobre **VALORANT**, apresentando diferentes aspectos do jogo por meio de páginas HTML.

O projeto foi desenvolvido como uma atividade acadêmica para colocar em prática conceitos de **HTML**, organização de páginas, links entre documentos, imagens, áudio, vídeo, formulários e elementos semânticos.

## 📚 Sobre o projeto

O site apresenta informações relacionadas ao universo de VALORANT, permitindo que o usuário navegue por diferentes páginas e conheça elementos do jogo.

A proposta é utilizar os conhecimentos adquiridos durante os estudos de desenvolvimento web para construir uma estrutura de site organizada utilizando HTML.

## 🎯 Objetivos

* Praticar a criação de páginas utilizando HTML.
* Aprender a organizar um site em várias páginas.
* Utilizar elementos semânticos do HTML.
* Trabalhar com imagens, vídeos e áudios.
* Criar formulários utilizando diferentes tipos de campos.
* Criar links e sistemas de navegação entre páginas.
* Desenvolver uma melhor organização de arquivos e pastas.
* Aplicar os conhecimentos de HTML em um projeto prático.

## 🕹️ Conteúdo

O projeto aborda diferentes assuntos relacionados ao VALORANT, incluindo:

* 🎯 Treino de mira;
* 💣 Plantio e desarme da Spike;
* 🧑‍🎤 Agentes e suas classes;
* 🎮 Noções básicas do jogo;
* 🏆 Informações para jogadores iniciantes;
* ❓ Quiz sobre VALORANT;
* 📖 Página de agradecimento.

## 💻 Tecnologias utilizadas

### HTML5

O projeto utiliza **HTML5** para construir a estrutura das páginas e organizar os conteúdos.

Entre os recursos utilizados estão:

* Estrutura básica do HTML;
* Tags semânticas;
* Títulos e textos;
* Links;
* Imagens;
* `figure` e `figcaption`;
* Áudio;
* Vídeo;
* Formulários;
* Listas;
* Tabelas;
* Elementos de navegação.

## 📝 Quiz

O projeto também possui uma área de quiz sobre VALORANT.

A finalidade do quiz é testar os conhecimentos do usuário sobre o conteúdo apresentado durante a navegação pelo site.

## 🌐 Navegação

As páginas são conectadas por meio de links HTML, permitindo que o usuário navegue entre diferentes partes do projeto.

Exemplo:

```html
<a href="outra-pagina.html">Próxima página</a>
```

## 🚀 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Entre na pasta `html`.
4. Localize a página inicial do projeto.
5. Abra o arquivo HTML no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para visualizar as páginas durante o desenvolvimento.
